## 每次验收先记录

记录提交 SHA、未提交差异、安装包版本/来源、Windows 版本、执行日期、测试数据、命令结果及证据位置。未执行的项目标为“未验证”，不沿用旧版结论。阶段记录写入对应日期的归档目录，并加入 [归档索引](archive/README.md)。

- [ ] Rust 编译与 storage_tests 通过：备份恢复、事务回滚、旧备份兼容、损坏数据拒绝与文件迁移保护。
- [ ] 两个 Python 引擎语法检查通过。
- [ ] `node tests/project-hub-schema.spec.mjs`：真实 SQLite 验证重复迁移、共享关联、进展修订快照、任务状态历史与回滚。
- [ ] 项目工作区回归：活动保存失败重试、文件复用、失联后重新定位、进展来源与草稿保留、修改历史、周报材料勾选、窄屏布局。

- [ ] 项目布局回归：标签的鼠标与键盘操作；概览显示当前行动，进展页不漏历史；切换项目和重启恢复资料选择、活动筛选、关键词与列表位置；无效缓存回退；400px 窄窗口一次显示列表或详情，返回恢复位置和焦点；缩放保留选择；查资料与新增活动不重分配已有进展草稿来源。
- [ ] 效率与专注回归：项目收藏、最近访问和归档 / 搜索范围一致，重启后恢复；切换器自动定位搜索框，Escape 返回；资料入口保护已有进展内容和来源；专注模式保留选区、显示保存错误并支持退出恢复；新记录默认日期与状态正确，跨日录入更新当天日期，主动选择的历史日期不被覆盖。
- [ ] 操作成本回归：默认 1200 × 700 窗口可直接续接项目和保存随手记；首页不重复显示记录历史、统计和常驻指南；工作记录不再嵌入项目管理；切换器的同一项目只出现一次；进展默认一句话保存，来源摘要清楚，折叠日期无效时自动展开提示；一次点击打开文件选择器；活动入口保护已有进展草稿；项目设置可归档和恢复。见 [操作成本回归](../tests/workspace-simplicity.spec.mjs)。
- [ ] 整套前端回归：宽窗项目列表与内容并排，窄窗文字导航可展开并循环焦点；工作记录直达正确项目且恢复筛选；会议列表与设置分类恢复；待办筛选紧凑且可清除；外部更新和刷新失败重试保留草稿，不重复写入；缓存异常回退和明暗主题可读。见 [前端重构回归](../tests/workspace-refactor.spec.mjs)。
- [ ] 连续工作回归：各页面独立恢复滚动位置；项目延迟加载后恢复位置，用户开始操作后停止恢复；旧记录修改状态明确，切换保留草稿，取消不写入，转为新记录使用当天日期和新标识；展开表单的可见标签和窄窗布局可用，记录提示不撑开横向滚动。见 [连续工作回归](../tests/workspace-continuity.spec.mjs)。

- [ ] 周报流程回归：编辑旧版与整理新版范围明确；材料及档案区分加载、空内容和失败，重试可恢复；外部刷新保留勾选与展开状态；没有选中材料不能生成；未保存正文有保护，生成/保存不能重复提交；400px 窄窗可用。见 [周报流程](../tests/weekly-report-workflow.spec.mjs)。
- [ ] `node tests/workbench-store.spec.mjs`：同一窗口共享初始读取与订阅；并发刷新合并并顺序执行；旧结果不覆盖新请求；重入请求等待自己的读取；失败可恢复，销毁后忽略晚到结果。
- [ ] 候选安装包生成成功；原生窗口关闭冒烟测试通过，并保留日志。安装包存在不代表测试通过。

## 原生端到端检查

| 场景 | 必须确认的结果 |
| --- | --- |
| 首次安装、旧版升级 | 能启动；旧资料完整；安装包版本正确 |
| 麦克风 / 系统声音录音 | 真实采集、停录保存、回放和时间戳跳转正常；最小化和恢复后数据完整 |
| 本地转写与说话人 | 引擎缺失有明确提示；安装后可运行；校对与改名可保存 |
| 智能纪要、问答、周报 | 实际配置的服务完成流程；失败可见，输入与已保存内容不丢；发送范围与说明一致 |
| 工作记录、项目、周报档案 | 重启后保留；解除关联或归档不误删资料；周报来源与所选日期/项目一致 |
| 保存、关闭、退出 | 关闭收起行为符合当前实现；退出等待待保存内容；录音或处理期间有保护 |
| 标准窗口与缩放 | 系统标题栏只出现一份；最小化到任务栏，最大化/还原及边缘调整尺寸正常；双击标题栏、系统菜单、贴靠操作可用；560px 内容高度下导航和设置仍可访问 |
| 项目工作区续接 | 项目标签与资料选择在重启后恢复；窗口缩放不清除草稿或改变来源；窄窗返回保留资料列表位置；原应用打开文件和重新定位使用隔离样本验证 |
| 备份恢复、目录迁移 | 使用隔离测试资料；恢复后资料与问答完整，迁移后音频可播放；明确数据库备份不含录音 |
| 本地 API / MCP | 默认关闭；查询范围有效；新增记录需显式写权限；停止后令牌失效 |
| 自动更新 | 旧版发现更新、下载校验和重启成功；最新版检查显示已是最新 |
