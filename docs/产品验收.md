# 产品验收清单

最后维护：2026-10-11。本文件是现行检查流程，不是“验收已通过”的声明。旧界面尺寸、历史测试结果见 [阶段记录](archive/2026-09-28/产品验收-阶段记录.md)。

## 每次验收先记录

记录提交 SHA、未提交差异、安装包版本/来源、Windows 版本、执行日期、测试数据、命令结果及证据位置。未执行的项目标为“未验证”，不沿用旧版结论。阶段记录写入对应日期的归档目录，并加入 [归档索引](archive/README.md)。

## 自动检查

功能与页面验收同时受 [核心价值及页面职责](个人工作台功能规划.md) 约束。自动测试通过后，仍须核对以下工作流程条件；设计目标未实现的项目保持未勾选。

- [ ] 本次改动能对应收集资料、继续项目、记录进展或复用成果中的具体场景，并说明减少了哪次查找或重复输入。
- [ ] 在项目、活动与资料间操作时继承当前归属；返回保留位置、筛选和草稿，用户不必重建同一套上下文。
- [ ] 同一资料与进展在项目、时间范围、搜索及周报中共用；没有因新增页面要求重复导入、分类或录入事实。
- [ ] 页面主要操作符合当前位置的职责；入口调整后原有资料和跨项目汇总仍可访问，常用工作无需在多个独立模块间反复跳转。
- [ ] 周报和 AI 使用实际可读内容，显示范围及可追溯来源；核对事实和保存结果能在当前工作中完成。
- [ ] 用同一组资料走通收集、正文搜索、来源定位、项目进展、周报复用和 MCP 读取；未支持的格式或未完成的能力明确标记，不能用各模块分别可用代替整条流程通过。
- [ ] 没有项目的临时资料也能先收集和找回；已有完成事件及进展不要求重复抄写；周报区分个人参与、他人行动和团队成果，同一成果在多处出现不重复计算。

- [ ] pnpm docs:check：现行文档的本地文件链接可解析。
- [ ] 前端构建通过；命令见 [开发指南](开发指南.md)。
- [ ] node tests/run-ui.mjs 通过：工作台、工作记录、全局搜索、提示组件及会议阅读交互；实际清单以 [测试入口](../tests/run-ui.mjs) 为准。
- [ ] Rust 编译与 storage_tests 通过：备份恢复、事务回滚、旧备份兼容、损坏数据拒绝与文件迁移保护。
- [ ] 会后 Python 引擎语法检查通过；模型准备只下载所需四类模型并复用已安装权重，不要求实时模型。
- [ ] 去实时录音回归：未配置模型仍能录音、周期保存音频、标记重点和记录笔记；最后笔记先于停录提交；结束后才转写与区分角色；自动保存不把新录音路径写回旧路径；旧会议仍可回听和校对。见 [会后录音回归](../tests/recording-after-meeting.spec.mjs)。
- [ ] `node tests/project-hub-schema.spec.mjs`：真实 SQLite 验证重复迁移、共享关联、进展修订快照、任务状态历史与回滚。
- [ ] 项目工作区回归：活动保存失败重试、文件复用、失联后重新定位、进展来源与草稿保留、修改历史、周报材料勾选、窄屏布局。
- [ ] [跨主题回归](../tests/project-themes.spec.mjs)：项目可关联多个主题，创建 / 改名 / 解除关联有反馈；主题汇总共享会议及资料只显示一次；切换项目保留主题选择草稿，失败不覆盖原关联；全量周报含日常事务，主题周报范围明确，历史名称及来源不随改名或解绑变化；400px 窄窗可用。
- [ ] 原生主题范围与备份回归：重复迁移、无效 / 冲突选择回滚、归档保留关联；项目授权与主题取交集，不读取同主题其他项目的记录或私有资料；新备份保留主题及周报范围，旧备份恢复清除新版本关系。
- [ ] [会议与项目回归](../tests/meeting-projects.spec.mjs)：会议可不关联项目、直接选择所属项目、项目与会议互跳；失败保留原关联，改换项目后仅显示原会议；项目可选择、打开、更换或解除本机文件夹，取消不写入，解除不删除原文件；窄窗关联选择和滚动标签仍可操作。
- [ ] 原生关联穿透：主项目派生活动与资料范围、主题及授权过滤一致，改归属后派生关系消失，已有跨项目引用保留；资料身份不复制。文件夹拒绝文件或失效目录，备份恢复路径，旧备份恢复时清除新路径；真实资源管理器打开需候选端核对。
- [ ] 好用性回归：侧栏直达项目、首页继续项目、一句话快捷保存、表单按需展开；项目目标/活动/进展草稿在切换和重新打开后保留；初次读取失败禁止提交，写入成功后的刷新失败提示不误导重复提交；打开文件和取消选择不额外刷新目录。
- [ ] 项目布局回归：标签的鼠标与键盘操作；概览显示当前行动，进展页不漏历史；切换项目和重启恢复资料选择、活动筛选、关键词与列表位置；无效缓存回退；400px 窄窗口一次显示列表或详情，返回恢复位置和焦点；缩放保留选择；查资料与新增活动不重分配已有进展草稿来源。
- [ ] 效率与专注回归：项目收藏、最近访问和归档 / 搜索范围一致，重启后恢复；切换器自动定位搜索框，Escape 返回；资料入口保护已有进展内容和来源；专注模式保留选区、显示保存错误并支持退出恢复；新记录默认日期与状态正确，跨日录入更新当天日期，主动选择的历史日期不被覆盖。
- [ ] 操作成本回归：默认 1200 × 700 窗口可直接续接项目和保存随手记；首页不重复显示记录历史、统计和常驻指南；工作记录不再嵌入项目管理；切换器的同一项目只出现一次；进展默认一句话保存，来源摘要清楚，折叠日期无效时自动展开提示；一次点击打开文件选择器；活动入口保护已有进展草稿；项目设置可归档和恢复。见 [操作成本回归](../tests/workspace-simplicity.spec.mjs)。
- [ ] 整套前端回归：宽窗项目列表与内容并排，窄窗文字导航可展开并循环焦点；工作记录直达正确项目且恢复筛选；会议列表与设置分类恢复；待办筛选紧凑且可清除；外部更新和刷新失败重试保留草稿，不重复写入；缓存异常回退和明暗主题可读。见 [前端重构回归](../tests/workspace-refactor.spec.mjs)。
- [ ] 连续工作回归：各页面独立恢复滚动位置；项目延迟加载后恢复位置，用户开始操作后停止恢复；旧记录修改状态明确，切换保留草稿，取消不写入，转为新记录使用当天日期和新标识；展开表单的可见标签和窄窗布局可用，记录提示不撑开横向滚动。见 [连续工作回归](../tests/workspace-continuity.spec.mjs)。
- [ ] 搜索与定位回归：四类结果都能命中，结果上限与真实总数区分，键盘可定位；工作记录草稿和原筛选保留，待办同页定位保留新增/行内草稿，返回恢复范围；读取失败可重试，勾选支持鼠标和键盘。见 [工作区搜索](../tests/workspace-search.spec.mjs)、[待办定位](../tests/task-search-navigation.spec.mjs)。
- [ ] 周报流程回归：编辑旧版与整理新版范围明确；材料及档案区分加载、空内容和失败，重试可恢复；外部刷新保留勾选与展开状态；没有选中材料不能生成；未保存正文有保护，生成/保存不能重复提交；400px 窄窗可用。见 [周报流程](../tests/weekly-report-workflow.spec.mjs)。
- [ ] `node tests/workbench-store.spec.mjs`：同一窗口共享初始读取与订阅；并发刷新合并并顺序执行；旧结果不覆盖新请求；重入请求等待自己的读取；失败可恢复，销毁后忽略晚到结果。
- [ ] 候选安装包生成成功；原生窗口关闭冒烟测试通过，并保留日志。安装包存在不代表测试通过。

CI 定义见 [Desktop CI](../.github/workflows/build-desktop.yml)。浏览器测试使用 tests 中的内存 IPC，不读写真实用户资料；截图在 .tmp/ui-verification/，CI 上传为 artifact。

## 原生端到端检查

| 场景 | 必须确认的结果 |
| --- | --- |
| 首次安装、旧版升级 | 能启动；旧资料完整；安装包版本正确 |
| 麦克风 / 系统声音录音 | 真实采集、停录保存、回放和时间戳跳转正常；最小化和恢复后数据完整 |
| 本地转写与说话人 | 引擎缺失有明确提示；安装后可运行；校对与改名可保存 |
| 智能纪要、问答、周报 | 实际配置的服务完成流程；失败可见，输入与已保存内容不丢；发送范围与说明一致 |
| 工作记录、项目、周报档案 | 重启后保留；解除关联或归档不误删资料；周报来源与所选日期/项目一致 |
| 保存、关闭、退出 | 关闭收起行为符合当前实现；退出等待待保存内容；录音或处理期间有保护 |
| 标准窗口与缩放 | 系统标题栏只出现一份；最小化到任务栏，最大化/还原及边缘调整尺寸正常；双击标题栏、系统菜单、贴靠操作可用；560px 内容高度下导航和设置仍可访问 |
| 项目工作区续接 | 项目标签与资料选择在重启后恢复；窗口缩放不清除草稿或改变来源；窄窗返回保留资料列表位置；原应用打开文件和重新定位使用隔离样本验证 |
| 备份恢复、目录迁移 | 使用隔离测试资料；恢复后资料与问答完整，迁移后音频可播放；明确数据库备份不含录音 |
| 本地 API / MCP | 默认关闭；查询范围有效；新增记录需显式写权限；停止后令牌失效 |
| 自动更新 | 旧版发现更新、下载校验和重启成功；最新版检查显示已是最新 |

## 发布门槛

- [ ] 当前提交的 CI、候选包与原生验收结果可追溯。
- [ ] 发布说明仅包含本次实际交付能力。
- [ ] 模型、FFmpeg 与依赖的分发许可及通知文件已核对。
- [ ] Windows 代码签名和 Tauri 更新签名分别核验。
- [ ] 安装包、.sig 和 latest.json 及其版本/下载地址一致，见 [发布手册](../RELEASE.md)。

只有取得证据后才勾选；前端回归不能代替真实录音、原生数据库、模型或更新验证。
