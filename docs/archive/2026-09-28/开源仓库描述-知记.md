# 知记（Zhiji）

**本地优先的个人工作台。** 开会、跟进行动项、翻问答、写周报——这些零散工作在一处沉淀：录音、转写、说话人区分、纪要、待办、问答记录全部保存在本地 SQLite 数据库里，可整库导出 Markdown、每日自动备份。

> 设计原则（个人项目，明确取舍）：**安全 > 顺手 > 便宜 > 少维护**。定位个人工作台而非通用笔记：只做「会议 → 待办 → 问答 → 周报」这一条主线，不做协作与商业化功能。

## ⑤ README「功能一览」要点（转写为你的语气即可）

- **一键录音**：麦克风 + 可选系统声音混音，实时字幕（本地引擎），自动保存、断录可恢复
- **离线转写**：本地中文语音模型，隐私不离开电脑；说话人区分后生成带时间戳的对话时间线，可改名
- **智能纪要**：6 种纪要模板 + 会前背景注入；超长会议自动分段生成再合并，不丢上下文；AI 自动命名
- **行动项待办**：纪要自动提取行动项（负责人/截止日），到期系统通知；与会议互跳，单独待办视图跟进
- **会议问答**：对单场会议任意追问（转写 + 纪要 + 笔记 + 会前背景），支持多轮追问
- **周报汇总**：一键把一周会议的纪要/待办汇总成个人周报
- **音文联动**：点击纪要/转写中的时间戳跳转回放原录音
- **全局搜索 / 深色模式 / 系统托盘 / 全局快捷键（Ctrl+Shift+K）/ 开机自启**

## ⑥ 开源许可与贡献建议

| 选项 | 说明 | 适合度 |
|---|---|---|
| **MIT（推荐）** | 最宽松，别人可随意使用/修改/商用，只需保留版权声明 | 想最大程度被采用 |
| Apache-2.0 | 宽松 + 明确的专利授权条款，大厂友好 | 有企业采用顾虑时 |
| GPL-3.0 | 传染性：衍生作品必须同样开源 | 介意被闭源商用包装 |

推荐 **MIT**：个人作品开源通常图「被用起来 + 留个名」；代码本身自研 + 引用开源库，MIT 无兼容负担。
