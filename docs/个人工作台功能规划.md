# 知记：个人工作台的功能与实施方案

## 产品方向

围绕一个用户每天会重复的流程设计：**随手收集 → 决定今天做什么 → 推进项目 → 回顾成果**。会议是信息入口之一，工作台负责把记录变成可查的资料和可执行的行动。

首批用户假设：经常开会、整理访谈、独立推进项目的个人。先通过实际试用验证使用频率和痛点，再决定收费套餐与后续投入。

## 本次正在完成

工作台概览、今日行动筛选、会议状态管理、负责人编辑、保存失败重试、关闭收起到托盘、退出前保存、深浅主题与窄窗口适配。构建与安装包验证使用 GitHub Actions；公众号介绍单独提供。

## 建议增加的功能

| 顺序 | 功能 | 用户获得什么 | 怎么实现 | 验收标准 |
| --- | --- | --- | --- | --- |
| 第一优先 | 快速收集箱 | 不开会议，也能随手记下一条想法、链接或临时任务 | 增加独立“收集”视图；复用本地 notes 表前先核对旧字段；增加保存、搜索、归档命令；通过显式“转为待办”建立来源关联 | 重启不丢内容；一次操作转为待办；保留原笔记；搜索可找到两者 |
| 第一优先 | 今日计划 | 在全部待办中明确今天主动要做的 3～5 件事 | tasks 增加 planned_date 与 priority；计划日期与截止日期分开；工作台提供“加入今天／移出今天”，按到期和优先级排序 | 修改计划不改变截止日；逾期不自动冒充今日计划；跨日行为明确 |
| 第一优先 | 周报档案 | 已生成的周报可以继续修改、保存和回看 | 新建 weekly_reports 表，保存日期范围、正文、来源会议、更新时间；生成后入库；编辑时自动保存；导出 Markdown | 关闭窗口后能重新打开；重新生成先保留旧版本；支持备份、恢复和整库导出 |
| 第二优先 | 项目空间 | 按一个项目集中查看会议、资料和待办 | 新建 projects 表；为会议、笔记、待办增加可空 project_id；增加项目详情与归档；迁移旧数据时默认“不分项目” | 旧资料完整可用；归档项目不删除资料；取消关联不删除任务；搜索仍覆盖已归档内容 |
| 第二优先 | 本地日程与重复待办 | 提前看到本周安排，定期工作不必重复输入 | 先做本地周视图与明确重复规则；使用 occurrence_key 防止重复生成；应用启动与跨日时补算 | 多次重启不重复创建；错过提醒能看到未完成事项；不会声称应用完全退出后仍能提醒 |
| 第二优先 | 完整迁移包与回收站 | 换电脑、误删除后能恢复工作资料 | 将数据库快照、录音、清单及校验值组成迁移包；导入到临时目录验证后再切换；删除先软删除，提供恢复与清空 | 断电不会覆盖可用库；恢复后录音可播放；旧数据库备份仍可读取；磁盘不足有明确提示 |
| 第三优先 | 跨资料检索与问答 | 不记得是哪场会，也能找到答案的出处 | 先用 SQLite FTS 对标题、正文、负责人建立索引；搜索稳定后再添加跨会议问答；回答附具体来源和时间戳 | 搜索可解释；无匹配时不编造答案；发送 AI 的资料范围可预览 |

## 推荐开发顺序

**第一阶段：把现有版本交付稳。** 修好关闭、退出、保存、备份边界；GitHub 构建通过；下载候选安装包验证全新安装、升级、录音、回放和恢复。结束条件是能够重复完成完整工作流程。

**第二阶段：补齐每天打开的理由。** 优先实现收集箱、今日计划和周报档案。三者分别解决“信息先放哪”“今天先做什么”“一周成果去哪了”。每个功能随同数据迁移、搜索、导出和恢复一起交付，避免形成新的孤立内容。

**第三阶段：围绕项目组织资料。** 在会议与待办已稳定关联的基础上增加项目空间，再增加本地周视图与重复事项。先验证个人流程，暂缓多人权限、实时协作和跨端同步的长期维护成本。

**第四阶段：用试用结果决定收费能力。** 观察实际使用的记录、检索与复盘路径，收集明确反馈后再设计许可与支持方案。若提供付费许可，密钥校验、离线宽限、换机和找回必须一起设计；若代付 AI，需要服务端限额、成本控制与失败退款规则。当前自带 API Key 的方式应继续清楚展示费用边界。

## 实施约束

- 新增资料统一写入 SQLite，使用带版本的迁移；备份、恢复、全量导出必须同步覆盖新表。
- 数据操作由 Rust 命令完成；React 显示成功必须以持久化成功为依据，失败保留输入。
- 记录来源使用稳定 ID，不通过标题猜测关联；删除、归档和解除关联含义分开。
- 明确展示本机处理与云端处理的范围。没有实际测量，不宣传识别准确率或节省时间比例。
- GitHub CI 是原生编译与安装包的交付入口；浏览器测试验证交互，Windows 候选包验证系统托盘、录音与更新。

上述新增功能是建议路线，尚未实现的部分不放进当前软件的宣传功能清单。
