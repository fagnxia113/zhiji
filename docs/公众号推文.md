# 知记：把会议、待办和周报，放进你的个人工作台

## 公众号摘要

开完会，工作才刚开始。知记把录音转写、智能纪要、行动待办、会议问答和周报汇总连接起来，让讨论有记录、事情有跟进、成果能回顾。本地优先，打造属于你的个人工作台。

## 正文

你有没有这样的时刻？

会开完了，录音还躺在文件夹里；讨论过的结论，要翻聊天记录才能找到；答应推进的事情，转眼又被新的任务打断。等到写周报，才发现这一周明明很忙，却要重新拼凑自己做了什么。

我们做了**知记**，希望把这些零散的工作，放回一个有条理的地方。

**知记是一款本地优先的 Windows 个人工作台。** 从会议记录到行动跟进，再到每周回顾，让每一次讨论都能成为下一步工作的起点。

### 打开工作台，先看清今天要做什么

本周有多少场会议，已经整理了多少篇纪要，还有哪些待办需要推进——打开知记，就能看到概览。

今天到期的事项、已经逾期的任务集中呈现；尚未整理的会议，也能接着上次的进度继续。少一些来回寻找，多一些对当下工作的把握。

### 开会时专注交流，会后有据可查

知记支持麦克风录音，也可以按需开启系统声音采集，或导入已有录音。

配置好本地语音引擎后，可以使用转写与实时字幕；会后校对原文、调整发言人姓名，再整理关键信息。需要确认细节时，支持从时间戳回到录音中的对应位置。

### 从一段讨论，整理出结论与行动

连接自己的 AI 服务后，知记可以按不同会议场景生成纪要，提炼决策与行动项。

生成的内容先预览、再确认保存；待办可以继续修改负责人和截止日期，并随时返回来源会议，找回任务背后的讨论。重要结论与任务安排，仍由你来校对和确认。

### 找答案、写周报，都能接着已有记录做

“这次会议为什么调整了方案？”“还有哪些问题没有解决？”

你可以围绕单场会议继续追问，让已有原文、纪要与笔记帮助你回顾上下文。到了一周结束时，再把会议成果和行动项汇总成周报草稿，修改后就能用于自己的工作汇报。

### 数据放在哪里，由你清楚掌握

知记默认把文字资料保存在本地数据库，录音保存在本机文件目录；支持数据库备份与 Markdown 导出。

本地转写在引擎与模型准备好后可离线运行。使用云端转写时，录音会发送给你配置的服务商；使用智能纪要、会议问答和周报功能时，相关文字会发送给所配置的 AI 服务。API 密钥由你提供，服务费用按服务商规则产生。迁移整套资料时，请一并保留录音目录。

**如果你经常开会、需要独立推进项目，也希望把每周成果整理得更清楚，欢迎试试知记。**

从下一场会议开始，把记录、行动和回顾，放进自己的工作台。
