# 开发指南

最后核对：2026-09-28。以下命令均在知记仓库根目录执行，即本地工作区中的 `anarlog/`，不是它的父目录。父目录另有历史仓库，执行 Git 命令前先用 `git rev-parse --show-toplevel` 核对位置。

## 环境与启动

- Node.js 22 或更高；pnpm 版本以根目录 `package.json` 的 `packageManager` 为准，当前为 11.1.1。
- 前端预览只需要 Node.js / pnpm；真实桌面开发还需要 Rust、MSVC 和 Windows 构建环境。
- 没有本地 Rust 环境时，可运行前端检查；原生编译、数据测试与候选安装包由 Windows CI 验证。

```bash
pnpm install --frozen-lockfile
pnpm --filter @zhiji/desktop dev
```

开发服务默认端口 1422。浏览器预览没有真实 Tauri IPC，不能据此判断录音或数据库可用；界面回归通过测试专用内存 IPC 验证交互。

启动完整桌面程序：

```bash
pnpm --filter @zhiji/desktop tauri dev
```

## 验证命令

```bash
pnpm docs:check
pnpm --filter @zhiji/desktop typecheck
pnpm --filter @zhiji/desktop build
pnpm exec playwright install chromium
```

PowerShell 下运行界面回归：

```powershell
$env:BROWSER_CHANNEL = 'chromium'
node tests/run-ui.mjs
```

测试默认使用本机 Chrome；上述环境变量选择 Playwright Chromium。测试入口自动启动和关闭 Vite；运行前确保 1422 端口可用。截图保存在 `.tmp/ui-verification/`。当前测试清单以 [run-ui.mjs](../tests/run-ui.mjs) 为准。

具备原生构建环境时运行：

```bash
cargo check --locked --manifest-path apps/desktop/src-tauri/Cargo.toml
cargo test --locked --release --lib --manifest-path apps/desktop/src-tauri/Cargo.toml
python -m py_compile apps/desktop/src-tauri/src/live_asr.py apps/desktop/src-tauri/src/speaker_engine.py
```

Rust 与 Python 检查不能由 TypeScript 检查替代。CI 的具体顺序及产物以 [Desktop CI](../.github/workflows/build-desktop.yml) 为准。

## 修改边界

变更依赖时同步更新 `pnpm-lock.yaml`，常规 CI 保持 `--frozen-lockfile`；Rust 使用已提交的 `Cargo.lock` 和 `--locked`。不要为通过构建而默认关闭锁文件检查。

新增或修改资料表时，同步覆盖迁移、搜索、导出、备份和恢复。测试使用独立临时数据；数据库备份不包含录音，迁移整套资料时须保留录音目录。发布流程见 [发布手册](../RELEASE.md)。
